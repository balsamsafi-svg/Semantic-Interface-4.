# Campus Service Desk

## Project Description
Campus Service Desk is a semantic HTML interface that allows students to submit campus service requests and view recent requests.

## Features
- Semantic HTML landmarks: header, navigation, main, and footer.
- A request form with labeled input, select, and textarea controls.
- A recent requests section using article elements.
- A logical heading hierarchy.
- Accessible form labels associated with their controls.

## How to Run
Open `index.html` in a web browser.

## Validation
The HTML document was checked using the W3C Nu HTML Checker. The result reported no errors or warnings.
